# Idea Shopping Website

A simple responsive shopping website built with HTML and CSS.

## What's included

- Responsive header and navigation
- Hero section
- Product categories
- Product cards
- Newsletter section
- Footer
- Responsive layout for desktop, tablet, and mobile

## Files

- `index.html` — page structure and content
- `style.css` — styling and responsive layout

## Running it

Download the files and open `index.html` in a browser.

The page uses Google Fonts and Unsplash images, so an internet connection is needed for those assets to load.
